CRASH FORGE: RACING v2.1.3 - NATIVE WINDOWS GAME
=================================================
Game executable: CrashForgeRacing.exe (Windows x86).

REQUIRES YOUR OWN LEGALLY OWNED ORIGINAL NTSC-U CTR DISC:
1. Extract ALL files to a writable game folder.
2. Provide your legally owned retail raw single-track MODE2/2352 image as:
       assets/ctr-u.bin
   A cooked 2048-byte ISO does not work.
3. Start CrashForgeRacing.exe.

CLEAN / NO-MODS MODE:
- The archive ships NO custom mods, profiles, settings, memory cards or disc data.
- Optional: run CrashForgeRacing.exe --no-mods to ignore local mod content.

LANGUAGES:
- The built-in language menu loads files in assets/localization/.
- Text localization is partial. Untranslated items use original English text.
- The original CTR font does not support all accented UTF-8 glyphs.

CNK 3D DRIFT METER:
- Options -> Gameplay -> Drift Meter -> CNK 3D.
- Use the in-game Meter Height option for the High/Low position.
- This setting is OFF in fresh installations until the player chooses it.
- Original CNK voice/sound/model assets are NOT part of this package.

Some custom tracks and heavier visuals remain experimental.
The game and launcher update independently.
