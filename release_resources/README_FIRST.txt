CRASH FORGE: RACING — EXPERIMENTAL WINDOWS BUILD

Use your own legally obtained raw NTSC-U Crash Team Racing disc image (MODE2/2352) placed at assets/ctr-u.bin. No original game data included.

Unzip all files to a writable game directory; launch ctr-native.exe. This is an experimental build: mods, custom tracks and graphics are work in progress. The launcher and game update independently.
