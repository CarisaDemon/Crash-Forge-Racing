# Crash Forge: Racing v2.1.0 — Experimental Windows Build

This is an **experimental native PC port** release. Please expect unfinished features and report regressions with steps to reproduce.

## Included
- Native Windows x86 build with unlocked frame-rate and higher-refresh modes.
- Modular racers, karts and wheels; new native mod package support and game Mods menu.
- Improved native HUD options, turbo and reserve calculations for higher FPS.
- Renderer performance experiments, profiling and GPU/culling diagnostics.
- Custom OGG/CSEQ audio and ongoing Hangout support.
- Early infrastructure for community custom tracks, still experimental.

## Known issues
- Custom tracks (including Assembly Lane) may have incorrect placement, incomplete collision or rendering defects.
- FPS in the pause menu are not gameplay FPS. Heavy tracks/bot races may still drop frames.
- Some graphics, custom models, camera angles, particles and HUD features remain in active development.
- Mods and configuration formats may change in future snapshots.

## Installation
Windows only. Bring your **own lawfully obtained** original NTSC-U Crash Team Racing disc image in raw MODE2/2352 format; put it at `assets/ctr-u.bin`. Original game data is **not distributed**.
This update contains no ISO, personal saved games, third-party mods or controller settings.

Launcher updates and game updates are independent. Bugs may be fixed in later v2.1.x snapshots.
